# M2M — MarIAno Web Market Analysis

## Intent
Given PROJECT_CONTEXT, analyze only market/customer/competition factors that should influence the website's structure, positioning, proof, messaging and conversion path.

## Instructions
- Prioritize competition, client ideal, offer, differentiation, objections, trust and purchase/consultation drivers.
- Avoid generic SWOT-style filler unless it changes a web decision.
- Distinguish observed facts from inference.
- Identify category conventions that should be followed versus overused patterns that create sameness.
- Translate every relevant finding into a specific website implication.

## Required output
For each material item return:
- FINDING
- BASIS
- CUSTOMER_IMPLICATION
- WEB_IMPLICATION
- RECOMMENDED_DECISION
- CONFIDENCE

Then return:
- POSITIONING_PRIORITIES
- TRUST_SIGNALS_REQUIRED
- OBJECTIONS_TO_RESOLVE
- DIFFERENTIATION_OPPORTUNITIES
- CONVERSION_PATH_RECOMMENDATION
- COMPETITOR_PATTERN_SUMMARY
