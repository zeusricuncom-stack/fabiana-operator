# FabIAna Operator

Sistema experimental para diseñar, validar y operar workflows web asistidos por IA sobre WordPress, Divi y WooCommerce.

## Objetivo
Convertir contexto desordenado de un cliente en una web investigada, diseñada, aprobada, construida y auditada con gates humanos antes de publicación.

## Workflow v0.1
1. Project Intake
2. Web Intelligence
3. Website Blueprint
4. Gate 1 — aprobación
5. Production
6. Visual + Tech QA Loop
7. Gate 2 — aprobación final
8. Publish

## Principios
- Research antes de diseño.
- Blueprint antes de producción.
- Assets planificados antes de ejecución.
- Draft/staging first.
- Read ≠ Act.
- Producción y acciones de alto impacto requieren autorización explícita.
- QA visual y técnico antes de entrega.
- Coherencia dentro de cada proyecto y diferenciación entre proyectos.

## Estado
